# HR Analytics Dashboard

## 🇫🇷 Présentation

Ce projet est un tableau de bord RH interactif développé avec Power BI afin d'analyser les départs d'employés (attrition), la démographie de la main-d'œuvre, les salaires et l'ancienneté.

L'objectif est de transformer des données RH en informations utiles pour soutenir la prise de décision.

## 🇬🇧 Overview

This project is an interactive HR Analytics Dashboard built with Power BI to analyze employee attrition, workforce demographics, compensation, and tenure.

The goal is to transform HR data into actionable insights that support business decision-making.

# 💡 Résultats clés | Key Insights

## Français

- Le département Research & Development présente le plus grand nombre de départs.
- Les employés âgés de 30 à 39 ans représentent la tranche d'âge la plus importante.
- La population étudiée est majoritairement masculine.
- Les niveaux de rémunération varient selon les départements.
- L'ancienneté moyenne est d'environ 7 ans.

## English

- Research & Development shows the highest attrition count.
- Employees aged 30–39 represent the largest workforce segment.
- The workforce is predominantly male.
- Salary levels vary across departments.
- Average employee tenure is approximately 7 years.
